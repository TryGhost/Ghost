# Docs

For contributors to the Ghost monorepo working on member custom field types. The pages are
arranged by what you need from them, following [Diátaxis](https://diataxis.fr/): a how-to
guide when you have a task in hand, and explanation when you want to know why things are the
way they are. The [package README](../README.md) covers using the package, and the comments in
`src/` describe each export.
