# Koenig Default Cards

## Install

`npm install @tryghost/kg-default-cards --save`

or

`npm install @tryghost/kg-default-cards`


## Usage


## Develop

This package is part of the Ghost monorepo, managed with pnpm workspaces.
Run `pnpm setup` in the monorepo root, then work in this directory.


## Run

- `pnpm dev`


## Test

- `pnpm lint` run just eslint
- `pnpm test` run lint and tests
