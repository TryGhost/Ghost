## 1.13.0

### Minor Changes

- Added `--kg-font-code-size` and `--kg-font-code-vertical-align` content font variables so a host can size and align inline code to suit its body font. They fall back to the current `.8em` and `middle`, so hosts that set none see no change.

### Patch Changes

- Bumped TryGhost SDK dependencies to their latest versions

- Fixed callout emoji pickers appearing behind automation and welcome email editors.
